**Grano & Click** es una plataforma de E-commerce integral diseñada para una cafetería. El proyecto destaca por un enfoque de desarrollo "End-to-End", iniciando con la validación de la experiencia de usuario (UX) y culminando en una arquitectura de backend robusta y escalable.

## Proceso de Diseño (UX/UI)
Antes de escribir una sola línea de código, el proyecto fue concebido bajo la metodología **Design Thinking**:
- **Figma:** Creación de prototipos de alta fidelidad.
- **User Experience:** Definición de flujos de usuario, paleta de colores y arquitectura de información para asegurar una navegación intuitiva.
- **Responsive Design:** Planificación de la interfaz para una adaptación fluida desde dispositivos móviles hasta escritorio.

---

### **Frontend**
- **HTML5 & CSS3:** Estructura semántica y estilos personalizados.
- **JavaScript (ES6+):** Lógica dinámica y manipulación del DOM.
- **Bootstrap:** Implementación de componentes responsivos y layouts ágiles.
- **Fetch API:** Conexión asíncrona con el backend para el consumo de datos en formato JSON.

### **Backend**
- **Java:** Lenguaje base para la lógica del servidor.
- **Arquitectura por Capas:** Organización del código en `Controller`, `Service` y `Repository` para un mantenimiento modular.
- **API REST:** Endpoints estructurados para la gestión de:
  - Productos
  - Usuarios
  - Pedidos

### **Persistencia y Entorno**
- **MySQL:** Diseño de base de datos relacional y gestión de entidades.
- **Postman:** Pruebas rigurosas de los endpoints y validación de respuestas HTTP.
- **WSL (Windows Subsystem for Linux):** Entorno de ejecución para simular condiciones de producción reales.

---

## Características Principales
- **Arquitectura Limpia:** Separación estricta entre la lógica de negocio y el acceso a datos.
- **Consumo de API:** Integración total entre el cliente (Frontend) y el servidor (Backend).
- **Entorno Profesional:** Configuración y ejecución sobre entornos Linux (WSL).
